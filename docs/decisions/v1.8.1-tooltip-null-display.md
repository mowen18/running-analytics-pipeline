# Revision v1.8.1 — 2026-07-24 — Null-safe temperature tooltips

Status: DRAFT — review before committing. Docs-before-code: this
addendum lands as a docs-only commit. The red test and app fix follow
in separate commits.

This is a narrow follow-up to the tooltip edge deferred by v1.8. It
lands after v1.9 but does not revise or supersede v1.9.

## Defect

`to_dataframe` converts database NULL numerics to pandas `NaN`. This
is correct for Streamlit tables, where missing values render as blank.
It is not correct for the two Altair temperature tooltips, which use
the raw quantitative fields and render the literal text `NaN`.

The affected sites are:

- The weekly efficiency point tooltip: `avg_temperature_f`, titled
  `avg air temp (°F)`.
- The cardiac-drift run tooltip: `temperature_f`, titled `air °F`.

The weekly edge was recorded in the v1.7 verification postscript and
deferred by v1.8. The current warehouse does not reach it, but the
data contract permits it.

The drift site is included. `mart_run_drift` selects successfully
analyzed drift candidates regardless of weather availability and
joins their `temperature_f` context without a NULL guard. A drift run
with no matched weather can therefore carry NULL `temperature_f`.

## Fix

Add one pure helper in `app/streamlit_app.py`:

`format_tooltip_1dp(series: pd.Series) -> pd.Series`

The helper converts each non-missing numeric value to a one-decimal
display string and converts each missing value to the em dash `—`.

Each chart adds a chart-local display column:

- `avg_temperature_f_display` for the weekly efficiency tooltip.
- `temperature_f_display` for the drift tooltip.

Both tooltip encodings switch to the corresponding nominal display
field. Their titles remain `avg air temp (°F)` and `air °F`.

The raw numeric columns remain unchanged. Tables continue to use
their existing numeric fields and render NULL as blank.

## Scope

Only the Streamlit presentation layer and its pytest coverage change.
No SQL, mart, schema, seed, dbt, ingestion, threshold, or data value
changes. The D19 mart allow-list and three-view cap remain unchanged.
